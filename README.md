## ขั้นตอนการติดตั้งและใช้งาน

### ช่องทางที่ 1: การอัปโหลดขึ้น GitHub และเชื่อมต่อ Vercel (โฮสต์ออนไลน์ทั่วไป)

1. **อัปโหลดโปรเจกต์นี้ขึ้น GitHub**:
   - สร้าง Repository ใหม่ใน GitHub (เช่น `self-assessment-2569`)
   - ทำการอัปโหลดไฟล์ `index.html` ไปไว้ที่ Root directory ของ Repository นั้น
2. **เชื่อมต่อกับ Vercel**:
   - ไปที่ [Vercel](https://vercel.com/) และล็อกอินด้วยบัญชี GitHub ของคุณ
   - กดปุ่ม **Add New** > **Project**
   - เลือก Repository ที่เพิ่งอัปโหลดไป
   - กด **Deploy** โดย Vercel จะตั้งค่าเริ่มต้นให้ดึงไฟล์ `index.html` มาแสดงผลโดยอัตโนมัติ
   - เมื่อ Deploy สำเร็จ คุณจะได้โดเมนเว็บลิงก์ของโครงการเพื่อส่งต่อให้ครูหรือผู้สนใจใช้งานได้ทันที

### ช่องทางที่ 2: การติดตั้งเป็น Google Apps Script Web App

1. ไปที่ [Google Drive](https://drive.google.com/) หรือ [Google Sheets](https://sheets.google.com) ของคุณ
2. สร้างโปรเจกต์ **Google Apps Script** ใหม่
3. ในโปรเจกต์สร้างไฟล์รหัส 2 ไฟล์:
   - ไฟล์รหัส (Script) ชื่อ **`code.gs`** (คัดลอกโค้ดจากไฟล์ `code.gs` ในโฟลเดอร์นี้ไปใส่)
   - ไฟล์ HTML ชื่อ **`index`** (คัดลอกโค้ดจากไฟล์ `index.html` ในโฟลเดอร์นี้ไปใส่)
4. ทำการบันทึกโปรเจกต์
5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)**
6. เลือกประเภทการทำงานเป็น **เว็บแอป (Web App)**
   - กำหนดสิทธิ์การเข้าถึงเป็น: **ทุกคน (Anyone)**
   - สั่งเริ่มทำงานในนามของ: **ตัวคุณเอง (Me)**
7. กด **Deploy** และคัดลอกเว็บลิงก์ (URL) เพื่อนำไปใช้งานหรือแชร์ต่อ

## จุดเด่นของแอปพลิเคชัน (Key Features)

*   **Responsive Design**: รองรับการใช้งานอย่างสวยงามและสมบูรณ์บนทุกหน้าจอ (สมาร์ทโฟน, แท็บเล็ต, คอมพิวเตอร์เดสก์ท็อป)
*   **Theme Customization**: ปรับธีมการแสดงผลได้ 3 รูปแบบ (สว่าง, มืด, อบอุ่น) เพื่อถนอมสายตาของผู้ใช้งาน
*   **Font Scaling**: ปรับขนาดตัวอักษรได้ 3 ระดับ (เล็ก, กลาง, ใหญ่) เพื่อความสะดวกในการอ่านของผู้บริหารและศึกษานิเทศก์
*   **Auto-Save (LocalStorage)**: บันทึกข้อมูลที่กรอกและหัวข้อที่ทำเครื่องหมายเช็กลิสต์ไว้ในบราวเซอร์อัตโนมัติ ป้องกันข้อมูลสูญหายเมื่อหน้าจอดับหรือกดรีเฟรช
*   **Warning Reset Confirmation**: ป้องกันการกดล้างข้อมูลโดยไม่ตั้งใจ ด้วย Pop-up แจ้งเตือนแบบ Custom UI สวยงาม
*   **Client-side PDF Exporter**: ปุ่มดาวน์โหลดผลการประเมินเป็น PDF พร้อมจัดรูปแบบฟอร์มสำหรับพิมพ์หน้าเดียวหรือออกรายงานอย่างเป็นทางการ (A4) พร้อมมีพื้นที่ลงลายมือชื่อยืนยัน
